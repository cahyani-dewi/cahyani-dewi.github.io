Portfolio Task 3

Policy Debate

View Task Brief

Objective: Produce two charts that support or refute a topic of policy debate

Richer, but not cleaner: should Vietnam stop waiting to fix its air?

Grow first, clean up later: A common view in development policy is that countries should grow first and clean up later. As incomes rise, demand for clean air rises too, and pollution eventually falls.

The first chart supports the "grow first" side. Vietnam's income per person more than tripled between 2000 and 2024, from about $4,350 to $14,400. By this measure, the growth strategy has clearly worked.

Yet the second chart shows that the "clean up later" part has not arrived. Average PM2.5 exposure rose from about 20 to 26 µg/m³ over the same period. It levelled off after 2007 but has not fallen, and it remains around five times the WHO guideline, slightly above Thailand and the Philippines.

Two decades of rapid growth have not moved Vietnam closer to safe air. Waiting for income alone to fix pollution looks unlikely to work. That strengthens the case for acting now, through tighter emission standards and a faster shift away from coal, rather than waiting until the country is richer.

Portfolio Task 5

Accessing Data

View Task Brief

Objective: Add chart that uses a live link to an API & using Google Collab python notebook, scrape a website.

API task: the digital divide by income group

This chart loads its data live from the World Bank Data360 API each time the page opens. Internet use has risen everywhere since 2005, but fewer than one in four people in low-income countries are online, against more than nine in ten in high-income countries.

Functional description of the API

The chart asks the World Bank Data360 API for the data every time the page opens. The API is free and needs no key.

API response (JSON) Chart specification
Base URL
https://data360api.worldbank.org/data360/data The Data360 host plus the /data endpoint, which returns observations. Parameters follow after ?, joined by &.
Elements of a call
DATABASE_IDrequiredWB_WDI: World Development Indicators
INDICATORWB_WDI_IT_NET_USER_ZS: internet users, % of population (WDI code IT.NET.USER.ZS, dots changed to underscores)
REF_AREALIC,LMC,UMC,HIC: the four income groups (low, lower-middle, upper-middle, high)
Data returned
JSON: a count plus a value list, with one row per income group per year. It is in long, tidy format, but values arrive as text and groups as codes, so the chart cleans them first.

Show cleaning steps
Rows nested under value"property": "value" in the data format
Year and value stored as textcalculate converts them to numbers
Groups as codes, such as LICcalculate maps them to readable names
About 25 fields per rowOnly 4 are used; the rest are ignored
New years added over timejoinaggregate finds the latest year for the end labels
Full URL
https://data360api.worldbank.org/data360/data?DATABASE_ID=WB_WDI&INDICATOR=WB_WDI_IT_NET_USER_ZS&REF_AREA=LIC,LMC,UMC,HIC
Base URL Database Indicator Areas

Why Data360? The older World Bank API (api.worldbank.org/v2) blocks requests made from web pages (it sends no CORS header), so a chart on this site can't load it. Data360 allows them.
