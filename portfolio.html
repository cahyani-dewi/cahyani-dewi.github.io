Portfolio Task 3

Policy Debate

View Task Brief

Objective: Produce two charts that support or refute a topic of policy debate

Richer, but not cleaner: should Vietnam stop waiting to fix its air?

Grow first, clean up later: A common view in development policy is that countries should grow first and clean up later. As incomes rise, demand for clean air rises too, and pollution eventually falls.

The first chart supports the "grow first" side. Vietnam's income per person more than tripled between 2000 and 2024, from about $4,350 to $14,400. By this measure, the growth strategy has clearly worked.

Yet the second chart shows that the "clean up later" part has not arrived. Average PM2.5 exposure rose from about 20 to 26 µg/m³ over the same period. It levelled off after 2007 but has not fallen, and it remains around five times the WHO guideline, slightly above Thailand and the Philippines.

Two decades of rapid growth have not moved Vietnam closer to safe air. Waiting for income alone to fix pollution looks unlikely to work. That strengthens the case for acting now, through tighter emission standards and a faster shift away from coal, rather than waiting until the country is richer.

Portfolio Task 5

Accessing Data

View Task Brief

Objective: Add chart that uses a live link to an API & using Google Collab python notebook, scrape a website.

Internet usage divide by income group

This chart loads its data live from the World Bank Data360 API each time the page opens. Internet use has risen everywhere since 2005, but fewer than one in four people in low-income countries are online, against more than nine in ten in high-income countries.

Functional description of the API

The chart uses the World Bank Data360 API. It is free and needs no API key. I used Data360 rather than the older World Bank Indicators API (api.worldbank.org/v2) because that API blocks requests made from a web page in the browser (it sends no CORS header). Data360 allows them, so Vega-Lite can call it directly.

a. Base URL

https://data360api.worldbank.org/data360/data

data360api.worldbank.org is the API host and /data360/data is the endpoint that returns observations. The data you want is chosen with query parameters added after ? and joined with &.

b. Elements needed to call the data

ParameterValue usedWhat it does
DATABASE_IDWB_WDIWorld Development Indicators.
INDICATORWB_WDI_IT_NET_USER_ZSThe indicator code for Individuals using the internet (% of population). It is the database ID plus the WDI code IT.NET.USER.ZS, with the dots replaced by underscores.
REF_AREALIC,LMC,UMC,HICThe areas to return, separated by commas. These are the four World Bank income groups: low, lower-middle, upper-middle and high income.

c. Data returned

The response is JSON. It is an object with two keys: count, the number of observations, and value, an array with one object per income group per year:

{
  "count": 84,
  "value": [
    {
      "DATABASE_ID": "WB_WDI",
      "INDICATOR": "WB_WDI_IT_NET_USER_ZS",
      "REF_AREA": "LIC",
      "TIME_PERIOD": "2025",
      "OBS_VALUE": "23.4",
      "UNIT_MEASURE": "PT",
      "SEX": "_T", "AGE": "_T", "URBANISATION": "_T",
      ...
    },
    ...
  ]
}

The value array is in long, tidy format: each row is one observation (income group × year), and each variable has its own field. This follows the SDMX statistical standard. It still needs some cleaning before it can be charted, and this is done with Vega-Lite transforms:

  • The rows sit under the value key, so the spec reads them with "format": {"type": "json", "property": "value"}.
  • OBS_VALUE and TIME_PERIOD come back as text, so calculate transforms convert them to numbers.
  • Groups come back only as codes (LIC), so a calculate transform maps them to readable names.
  • Each row has about 25 fields, mostly SDMX dimension codes such as SEX: "_T" (total). The chart uses only four of them.
  • Only years with data are returned (2005 onwards), and rows are not sorted by year. A joinaggregate transform finds the latest year, so the end labels update on their own when new data is published.

Full final URL used in the chart

https://data360api.worldbank.org/data360/data?DATABASE_ID=WB_WDI&INDICATOR=WB_WDI_IT_NET_USER_ZS&REF_AREA=LIC,LMC,UMC,HIC
