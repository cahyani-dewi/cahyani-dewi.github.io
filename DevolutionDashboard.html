Portfolio Task 6

Has devolution helped England's city regions catch up with London?

View Task Brief

Objective: Locate sub-regional UK data and make a dashboard of 6 charts to explain devolution in some way. Use a loop to batch download six series as JSON files, save them to GitHub and use them as raw files to supply the charts.

England's first metro mayors were elected in 2017, with new powers over transport, skills and growth. These charts compare six established mayoral combined authorities with Greater London (dashed grey) on the economy, work, health, the environment and ageing. Hover over a chart to see every area's value for that year.

Data: PP434 strategic-authority datasets compiled from ONS (regional GVA, ASHE, Annual Population Survey, mid-year population estimates, life expectancy) and DESNZ (local emissions). Each series was downloaded in a Python loop, reshaped to tidy format and saved as JSON in this site's repository.

Analysis notebook: Google Colab notebook
